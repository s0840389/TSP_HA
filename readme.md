# Heterogeneous Agent Models

**Economic Modelling and Forecasting – Centre for Central Bank Studies, Bank of England**

Jamie Lenney · October 2026

Slides and code for an introductory lecture on heterogeneous agent (HA) models: why incomplete markets matter, how income risk and borrowing constraints drive household saving, and how to solve and simulate a Huggett model.

## Slides

* **PDF:** [main_ccbs.slides.pdf](main_ccbs.slides.pdf)
* **HTML (reveal.js):** [main_ccbs.slides.html](main_ccbs.slides.html) – download and open in a browser (needs an internet connection for reveal.js and MathJax)
* **Notebook with all the code:** [main_ccbs.ipynb](main_ccbs.ipynb)

## Contents

* Incomplete markets and the precautionary savings motive
* The household consumption–savings problem: Bellman equation, Euler equation and borrowing constraints
* Solution methods: value function iteration (VFI) and the endogenous gridpoint method (EGM)
* The stationary wealth distribution (forward iteration)
* Equilibrium in a Huggett model: asset demand, interest rates and borrowing constraints
* Aggregate dynamics: TFP and news shocks using the sequence-space Jacobian

## Running the code

The Python code uses the [sequence-jacobian](https://github.com/shade-econ/sequence-jacobian) toolkit:

```bash
pip install sequence-jacobian numpy matplotlib jupyter
```

Then open `main_ccbs.ipynb` and run all cells (about 40 seconds). Figures are saved to `figures/`.

MATLAB code solving a Huggett economy with VFI is in [Huggett_matlab/](Huggett_matlab/) (run `Huggett_Main.m`).

## Rebuilding the slides

```bash
./build_slides.sh              # notebook -> main_ccbs.slides.html + main_ccbs.slides.pdf
EXECUTE=1 ./build_slides.sh    # re-run the notebook first (regenerates the figures)
```

Requires `jupyter nbconvert`, Google Chrome or Chromium (for the PDF) and an internet connection. The Bank of England styling lives in [slides_template/boe](slides_template/boe); after changing the logo, run `python slides_template/make_assets.py`.
